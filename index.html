Features

Everything a memory patcher needs

Built around a fast script loader and a clean, readable outcome pipeline.

🔍

Live Memory Scanner

Search process memory by value, type, and region. Narrow results instantly and pin the addresses that matter to your outcome run.

🩹

Game State Patching

Write patched values back into a running process with byte-level precision. Apply single edits or batch a whole patch set from one script.

📸

Outcome Snapshots

Dump the full outcome state into a portable snapshot file. Capture a run before it changes and keep every result reproducible.

♻️

Memory Restore

Reload a saved snapshot to restore memories exactly as they were — same addresses, same values, same outcome outcome tree.

🧩

Script Loader Ready

Drop the module into any compatible loader. A single entry point exposes scan, patch, dump, and restore as simple script calls.
